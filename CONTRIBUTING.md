# Contributing

Bug reports should include the operating system, packager and version, a minimal build configuration, expected result, and actual result. Do not attach private signing keys or proprietary application bundles.

For code changes:

1. Add a small fixture or unit test that reproduces the failure.
2. Keep checks deterministic and offline.
3. Run `python -m unittest discover -s tests -v`.
4. Explain false-positive risk in the pull request.
